## 🎯 About Diya

**Diya** (दिया - meaning "lamp" in Hindi) is an innovative **AI-powered mental health detection platform** developed as a **Smart India Hackathon** project. It leverages advanced machine learning and generative AI to analyze user responses, detect potential mental health concerns, and provide personalized support, resources, and chatbot-based guidance through an intuitive, responsive web interface.

### 🌟 Mission

To make mental health support accessible to everyone by providing intelligent, compassionate, and real-time mental health analysis and support systems.

## 🚀 Getting Started

### Prerequisites
```
Node.js 14+
MongoDB
npm or yarn
Git
```

### Installation

```bash
# Clone the repository
git clone https://github.com/mohammedsaniya55-hash/AI-Mental-Health-Detection.git
cd AI-Mental-Health-Detection

# Install frontend dependencies
npm install

# Install backend dependencies (if separate folder)
cd backend
npm install

# Set up environment variables
cp .env.example .env

# Add your configuration to .env file
```

### Running the Application

```bash
# Start frontend (from root directory)
npm start

# In another terminal, start backend (if applicable)
cd backend
npm start

# Access at http://localhost:3000
# API at http://localhost:5000
```

## 🧠 Mental Health Detection Engine

### Assessment Categories

- **Emotional Health** - Emotional stability and regulation
- **Social Wellness** - Social connections and relationships
- **Cognitive Function** - Mental clarity and focus
- **Physical Wellbeing** - Sleep, exercise, and physical health
- **Stress Levels** - Anxiety and stress management
- **Work-Life Balance** - Career satisfaction and balance
- **Resilience** - Coping mechanisms and adaptability

### Output Analysis

The system provides:
- ✅ Risk assessment score (0-100 scale)
- ✅ Identified mental health concerns
- ✅ Personalized recommendations
- ✅ Relevant resource links
- ✅ Professional guidance suggestions
- ✅ Chatbot conversation support

## 📱 API Endpoints

```
Authentication
POST   /api/auth/register        - User registration
POST   /api/auth/login           - User login
POST   /api/auth/logout          - User logout

Assessment
POST   /api/assessment/submit    - Submit assessment
GET    /api/assessment/{id}      - Get assessment results
GET    /api/assessment/history   - Get assessment history

Chatbot
POST   /api/chat/message         - Send chat message
GET    /api/chat/history         - Get chat history

Resources
GET    /api/resources            - Get support resources
GET    /api/resources/{category} - Get resources by category

User
GET    /api/user/profile         - Get user profile
PUT    /api/user/profile         - Update profile
GET    /api/user/dashboard       - Get user dashboard
```

## 🔧 Configuration

Update `.env` file:

```env
# Frontend
REACT_APP_API_URL=http://localhost:5000

# Backend
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret_key
NODE_ENV=development

# AI/ML
AI_MODEL_PATH=./models/health_detection.pkl
ENABLE_RECOMMENDATIONS=true

# Security
ENABLE_ENCRYPTION=true
DEBUG_MODE=false
```
